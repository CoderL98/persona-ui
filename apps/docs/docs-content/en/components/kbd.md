# Kbd

## Import

```svelte
<script>
  import { Kbd } from '@persona-ui/lib';
</script>
```

Keyboard shortcut display.

## API

| Prop       | Type      | Default | Description |
| ---------- | --------- | ------- | ----------- |
| `children` | `Snippet` | —       | Key label   |

## Usage

```svelte
<Kbd>⌘K</Kbd>
<Kbd>Ctrl + S</Kbd>
```
