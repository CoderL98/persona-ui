# Central Registry

Persona UI 的主题注册中心——第三方作者可以基于 `@persona-ui/lib` 创建/分发主题，
用户可以一条命令安装到自己的项目。

## Why a Central Registry

- **复用 lib 的所有组件**（Button / Card / Dialog / ...）
- **复用 lib 的 token 系统**（`--pui-color-primary` 等 83 个 semantic token）
- **自己只管"长什么样"** —— CSS + themeDef
- **CI 自动校验** —— token 覆盖 / CSS 语法 / 视觉回归 / scope 校验

## Quick Start (Contributing)

### 1. Fork the repo

```bash
gh repo fork rcc/persona-ui --clone
cd persona-ui
pnpm install
```

### 2. Create `packages/theme-{id}/`

按 [Theming Guide](/docs/theming) §2 模板创建包结构：

```bash
mkdir -p packages/theme-{id}/src
```

必填文件：

- `package.json` — 声明 `peerDependencies: { "@persona-ui/lib": "..." }`
- `tsconfig.json`
- `src/index.ts` — 导出 `themeDef`
- `src/{id}.css` — 主题 CSS（含 light + dark）

### 3. Write `themeDef` + CSS

```ts
// src/index.ts
import type { ThemeDef } from "@persona-ui/lib";

export const themeDef: ThemeDef = Object.freeze({
  id: "{id}",                              // kebab-case, globally unique
  label: "{Display Name}",
  labelKey: "toggleTheme_{id}",
  iconSvg: "<path d='...' />",
  cssVarPrefix: "pui-{id}",                // globally unique
  darkSupport: true,
  packageName: "@persona-ui/theme-{id}",
});
```

### 4. Add Token Coverage Test (Required)

`@persona-ui/lib` 导出一个 `tokens-manifest.json`，列出了**所有**通用 semantic token。
你的主题必须**全部覆盖**，否则升级 lib 时组件会"裸 HTML 外观"。

```ts
// src/__tests__/tokens.test.ts
import manifest from "@persona-ui/lib/tokens-manifest";
import { readFileSync } from "node:fs";

const css = readFileSync("dist/{id}.css", "utf-8");

for (const token of manifest.tokens.semantic) {
  test(`covers --${token}`, () => {
    expect(css).toMatch(new RegExp(`--${token}:`));
  });
}
```

在 `package.json#scripts` 加：

```json
"test:tokens": "vitest run --dir src/__tests__ tokens"
```

### 5. Submit PR

CI 会自动跑：

1. **Scope guard** —— `@persona-ui/theme-*` 命名权校验
2. **Token coverage** —— 跑 `test:tokens`
3. **Stylelint** —— CSS 语法
4. **Visual regression** —— Playwright 截图对比
5. **CLI unit tests** —— 保证 `add` 命令能拉你的 manifest

通过后仓库所有者会跟进一个 follow-up PR 把你注册到 `apps/docs/static/r/{id}.json`。

## Naming Convention

| 命名 | 用途 | 谁可以发布 |
|------|------|----------|
| `@persona-ui/theme-{id}` | 官方主题 | **仅仓库所有者**（CI scope-guard 强制） |
| `@<your-scope>/theme-{id}` | 第三方 fork | 任何 npm 用户 |
| `@community/theme-{id}` | 社区主题 | GitHub 组织成员 |

## Install (User Perspective)

### Option A: Direct npm install

```bash
# 官方主题
pnpm add @persona-ui/lib @persona-ui/theme-apple

# 第三方主题
pnpm add @persona-ui/lib @acme-ui/theme-corp
```

### Option B: CLI (1-line install)

```bash
# Browse available themes
pnpm dlx @persona-ui/cli list

# Get details for a specific theme
pnpm dlx @persona-ui/cli info theme-apple

# Install a theme to your project (default: ./src/lib/pui-themes/<name>/)
pnpm dlx @persona-ui/cli add https://persona-ui.ricecakecat.com/r/theme-apple.json

# Or from local path (dev/debug)
node apps/cli/src/index.ts add apps/docs/static/r/theme-apple.json
```

**CLI commands:**

| Command | Purpose |
| ------- | ------- |
| `list [registry-url]` | List all themes in the registry index (default: `https://persona-ui.ricecakecat.com/r/registry.json`) |
| `info <theme-name>` | Show full manifest: deps, files, install command |
| `add <source>` | Fetch a theme and copy its files to your project |

CLI 会自动：

1. 验证 manifest schema
2. 提示 `registryDependencies`
3. 拷贝 CSS / themeDef / README 到目标目录
4. 打印后续注册提示

## FAQ

**Q1: Can I use `@persona-ui/theme-*` for my own fork?**
No. This scope is reserved for the repo owner. CI `scope-guard` will block your PR.
Use `@<your-scope>/theme-{id}` instead.

**Q2: How do I get listed in `registry.json`?**
After your PR passes all CI checks, the repo owner will submit a follow-up PR adding
your manifest to `apps/docs/static/r/{id}.json`. Mention `@rcc` in your PR description.

**Q3: My theme only supports light mode?**
Set `darkSupport: false` in your `themeDef`. Document the fallback in your README.

**Q4: Can my `cssVarPrefix` be the same as another's?**
No. Conflicts cause CSS selector pollution. Check the [discussions](https://github.com/rcc/persona-ui/discussions) first.

**Q5: Does CI run on forks?**
Yes. All checks are public and don't require secrets.
