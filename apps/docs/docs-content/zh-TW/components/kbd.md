# Kbd 鍵盤按鍵

## Import

```svelte
<script>
  import { 鍵盤按鍵 } from '@persona-ui/lib';
</script>
```

用於展示鍵盤快捷鍵。

## API

| Prop       | Type      | Default | Description |
| ---------- | --------- | ------- | ----------- |
| `children` | `Snippet` | —       | 按鍵標籤    |

## 用法

```svelte
<Kbd>⌘K</Kbd>
<Kbd>Ctrl + S</Kbd>
```
