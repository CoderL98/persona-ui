# Kbd 键盘按键

## Import

```svelte
<script>
  import { 键盘按键 } from '@persona-ui/lib';
</script>
```

用于展示键盘快捷键。

## API

| Prop       | Type      | Default | Description |
| ---------- | --------- | ------- | ----------- |
| `children` | `Snippet` | —       | 按键标签    |

## 用法

```svelte
<Kbd>⌘K</Kbd>
<Kbd>Ctrl + S</Kbd>
```
